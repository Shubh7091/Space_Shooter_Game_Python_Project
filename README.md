SPACE SHOOTER GAME - PYTHON PROJECT
===================================

ABOUT
-----
A simple 2D Space Shooter game made using Python and Pygame.
Control the spaceship, shoot enemies, earn points, and survive.

FEATURES
--------
- Move spaceship left and right
- Unlimited bullets
- Random enemy spawning
- Score system
- 3 Lives
- Game Over and Restart option

REQUIREMENTS
------------
Python 3
Pygame

INSTALLATION
-----------
Install Pygame using:

pip install pygame

HOW TO RUN
----------
1. Save the code as space_shooter.py
2. Open terminal in the project folder.
3. Run:

python space_shooter.py

CONTROLS
--------
LEFT ARROW  - Move Left
RIGHT ARROW - Move Right
SPACE       - Shoot
R           - Restart
ESC         - Exit

PYTHON CONCEPTS USED
--------------------
- Modules
- Variables
- Lists
- Functions
- While Loop
- For Loop
- Conditional Statements
- Recursion
